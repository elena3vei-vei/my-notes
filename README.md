# Мои заметки

Учебный репозиторий для знакомства с GitHub.

## Что здесь можно делать

- Хранить заметки и инструкции.
- Редактировать файлы прямо в браузере.
- Смотреть историю изменений.
- Пробовать ветки и pull request.

## Как изменить файл в браузере

1. Открой нужный файл.
2. Нажми значок карандаша (Edit).
3. Внеси изменения.
4. Нажми Commit changes и напиши, что изменилось, например: «Добавить новую заметку».
5. Сохрани изменения.

## Короткий словарь

| Термин | Значение |
| --- | --- |
| Репозиторий | Файлы проекта и история изменений |
| Коммит | Сохранённый набор изменений с пояснением |
| Ветка | Отдельная линия работы |
| Pull request | Предложение объединить изменения из ветки с основной версией |
| Merge | Объединение изменений |

Основная ветка этого проекта — `main`.

## Первое упражнение

Открой вкладку Pull requests: там будет учебный пример добавления файла `notes.md`. В нём можно посмотреть изменения перед объединением.

## Доступ

Репозиторий публичный. Не добавляй пароли, ключи доступа и личные данные.
