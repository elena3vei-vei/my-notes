## Что попробовать

- [ ] Изменить заголовок этой заметки.

## Как работает пример

1. Ветка `first-note` создана из основной ветки `main`.
2. Этот файл добавлен отдельным коммитом.
3. Pull request показывает разницу между ветками.
4. После Merge файл появится в основной ветке.
